# 💄 Cosmetic Shop Management Dashboard

##  Project Overview

The Cosmetic Shop Management Dashboard is an interactive Power BI project designed to analyze sales, customers, products, inventory, suppliers, and returns.
The dashboard provides actionable business insights to help understand overall shop performance, product demand, inventory status, supplier performance, and customer returns.

##  Project Objectives

* Analyze overall sales and profit performance
* Track customers, orders, and products
* Monitor inventory and stock availability
* Identify low-stock products
* Analyze supplier performance
* Understand product return patterns
* Identify major return reasons
* Support data-driven business decisions
